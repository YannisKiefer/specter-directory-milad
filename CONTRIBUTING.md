# Contributing

Thanks for helping grow the list! 🎉

1. One skill per pull request.
2. Format: `- [name](link) - Short description ending with a period.`
3. Add it to the right category, at the end of the list.
4. The skill must be public, open source, and contain a valid `SKILL.md` with `name` and `description` frontmatter.
5. Only list skills that work and are documented. No placeholder or empty repos.
6. Self-promotion is fine, as long as the skill is genuinely useful.
